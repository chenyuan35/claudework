# Visual Standard

Use this when creating Douyin image-post assets.

## Quality Bar

- First image must stop scrolling in 1 second.
- Use full-bleed photographic or editorial visuals when possible.
- Prefer real scenes: street, room, kitchen, market, bus stop, laundromat, stairwell, window, desk, rainy road.
- Keep one strong focal subject and one text-safe negative-space area.
- Use refined Chinese typography added locally, not generated inside the image.
- Make a sequence feel like a small work: hook, expansion, detail, turn, closing line.
- Prefer 3:4 or 9:16 vertical assets. Use 3:4 when the platform preview benefits from a denser image; use 9:16 when the visual scene needs immersion.
- For early account testing, ship 3-6 images per post instead of long decks.
- Treat a single user-provided image as a quality reference only unless the user explicitly says to copy its style. Do not infer that the user wants the same darkness, topic, scene, color palette, mood, character setup, or story.
- Do not overfit to one visual style. Build a varied test matrix across bright, clean, warm, cute, useful, emotional, product, and lifestyle styles.

## Avoid

- Plain PPT-like cards as the default.
- Copying a reference image's exact scene, text, pose, or story.
- Turning one reference image into the whole account style.
- Defaulting to dark cinematic images just because one reference image is dark.
- Fake brand labels, fake Chinese text, watermarks, cluttered collages, low-resolution screenshots.
- Too many fonts, heavy stickers, cheap template feel.

## Default Test Matrix

Use these as the first 7-day visual tests unless account data says otherwise:

1. Bright useful list: clean home/life scenes, large readable title, high save value.
2. Warm lifestyle: morning kitchen, desk, balcony, soft sunlight, practical copy.
3. Product/object close-up: everyday item, clean background, one buying/avoidance point.
4. Cute light humor: simple scene, playful title, share/comment bait.
5. Minimal diary: quiet but not dark, short emotional copy, soft color.
6. Contrast before/after: one clear problem and one clear solution.
7. City observation: only one slot, not the default account style.

## Visual Families

### City Smoke

Night streets, convenience stores, food stalls, laundromats, bus stops, rental rooms. Warm/cool mixed light, ordinary people, restrained emotional copy.

Best for: emotional stories, urban observation, "ordinary people" resonance.

### Clean Practical

Realistic household scenes, object close-ups, bright natural light, concise buying/organizing advice. Use this for utility posts.

Best for: useful lists, home/life tips, shopping avoidance, save-worthy content.

### Quiet Diary

Windows, desks, bedsides, morning kitchens, rainy balconies. Minimal copy, soft light, personal but not melodramatic.

Best for: personal resonance, late-night mood, quiet relationship/life observations.

## Cover Rules

- Cover decides click-through. It must have either a strong person, strong object, or strong scene.
- Main text should be short. Avoid large paragraphs on the cover unless the account is intentionally literary.
- Use contrast: dark scene + light text, or quiet scene + one sharp sentence.
- Do not make the cover look like a tutorial slide unless the post is a pure tutorial.

## Publishing Add-Ons

- Add BGM that matches mood: pure piano/ambient for emotional posts; light rhythm for practical posts.
- Use 4-5 hashtags: one core niche, one image-text tag, one scene/topic tag, and one broad discovery tag.
- Add a first comment after posting that invites response, not spam.

## Typography

- Main copy: 28-48 px on 1080x1920 depending on line length.
- Keep line length short; use breathing space.
- Highlight only 1-2 keywords in warm yellow or muted accent.
- Leave bottom UI-safe area uncluttered.
