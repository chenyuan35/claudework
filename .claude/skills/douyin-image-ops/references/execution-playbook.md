# Douyin Image Account Execution Playbook

Use this as the default operating standard before producing content.

## What Was Learned

Sources checked:

- Douyin Creator Center: https://creator.douyin.com/
- 巨量星图图文任务案例: https://www.xingtu.cn/post-author/132874
- 图文产品分析: https://www.woshipm.com/it/5852447.html
- Canva 抖音长图教程: https://www.canva.cn/learn/tiktok-long-figure/
- 抖音封面设计教程: https://www.designkit.cn/topic/tiktok-cover

Operational takeaways:

- Douyin image posts are not just mini Xiaohongshu. The image itself must carry most of the information.
- Cover image is the first gate. It needs a clear subject, clear benefit or emotion, and readable text.
- BGM still matters because Douyin image posts are consumed in a video-like feed.
- Image posts often win on collection and interaction. Optimize for saves, comments, and shares, not only likes.
- Commercially useful categories include fashion, food, travel, home/lifestyle, daily-use goods, and practical guides.
- Good image posts are either high-density useful content or high-quality visual/emotional content. Weak middle-ground cards perform badly.

## Default Account Direction

Do not use AI as the niche.

Use a 14-day test matrix instead of locking the account to one visual style:

1. Home/life practical list.
2. Daily-use shopping avoidance.
3. Clean object close-up + one point.
4. Bright lifestyle scene + short useful text.
5. Food/home routine.
6. Light humor/life complaint.
7. Soft emotional diary.

Keep the current account profile unchanged.

## Post Structure

Use 3-6 images by default.

1. Cover: strong subject + short title.
2. Setup: problem, scene, or promise.
3. Main content: first useful point or story turn.
4. Main content: second point or contrast.
5. Summary: save-worthy line.
6. Interaction: optional, only if natural.

## Cover Rules

- Do not ship a cover without a clear focal subject.
- Use text no more than 2 lines for practical posts.
- Use one strong visual: person, object, food, room, desk, street, product, before/after.
- Prefer bright, clean, warm, or high-contrast visuals for early testing. Dark cinematic visuals are only one test slot.
- Do not copy a reference image's topic, lighting, scene, pose, wording, or mood unless explicitly requested.

## Content Types To Produce First

Use these before making abstract emotional posts:

- "别乱买" household daily-use list.
- "第一次自己住" checklist.
- "租房党" practical guide.
- "厨房/卫生间/收纳" before-after.
- "普通人省钱" small actionable list.
- "好用但不贵" object close-up.

## Publish Package

Each post must include:

- Title.
- 3-6 image assets.
- Caption.
- 4-5 hashtags.
- BGM direction.
- First comment.
- Review metric target.

## Review Metrics

For early posts, decide next moves by:

- 3-second retention / first-page click-through signal.
- Swipe completion.
- Saves.
- Comments.
- Follows.
- Whether one topic produces repeatable variants.
