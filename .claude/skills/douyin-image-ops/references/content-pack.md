### Titles

Provide 5 title options:

1. Pain-point title
2. Curiosity title
3. Benefit title
4. Contrarian title
5. Plain useful title

### Carousel Script

Use 3-6 images by default for early testing. Use up to 9 only when the story or tutorial genuinely needs it.

Default sequence:

1. Cover: visual focal point and hook.
2. Problem or emotional setup.
3. Core turn or first useful point.
4. Detail, contrast, or second useful point.
5. Closing line or summary.
6. Follow/interaction page only when it does not cheapen the work.

### Image Prompt Rules

- Keep one visual idea per page.
- Make text area clear and uncluttered.
- Use consistent character, color, lighting, and camera language across pages.
- Avoid tiny text inside generated images; prefer adding Chinese text in layout tools.
- Include aspect ratio and composition.

### Pre-Publish Check

- Cover can be understood in 1 second.
- First 3 pages create curiosity or utility.
- Claims are not absolute unless evidence is provided.
- Each page has one job.
- CTA is natural, not spammy.
